# TUI feature requests

- [ ] `content` field in the `events.jsonl` must be displayed in full, never
      truncated or folded.
- [ ] Use `Ctrl + u/d` for scrolling, like vim.
- [ ] Support mouse scrolling: Currently, though not claimed supported, the tui can
      be scrolled by mouse, but it is very laggy and uncontrollable, and will hang
      the process: double `q` cannot exit, no response to other key inputs.
- [ ] Syntax highlight for the tool results if possible, markdown syntax highlight
      and proper rendering for `content`.
