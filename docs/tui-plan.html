1. Position

The TUI is the first stateful, long-lived, interactive Rust binary in the harness. It is a window onto the session log and a supervisor for the opaque loop. It is stateful as a view: cursor, scrollback, draft and child-process handles live in memory; session state lives in the log. A crash loses nothing — restart re-renders from the log.

5. Tailer (file watch) decisions

The tailer thread exits when its channel disconnects or when the process ends. It never re-emits: the offset advances only after a successful send, so bounded backpressure cannot lose or duplicate an event.

  • Transcript pane: per-event semantic rendering. Message and tool output wrap across as many lines as they need, capped per event with a hint. Blank line between events. Continuation lines align under the content gutter.
  • Tool results show the tool's text payload (or stdout/stderr), not the raw JSON value envelope. The header carries exit N / (error) and error output renders red.
  • Pending approval_request renders as a banner row above the input line (derived from the log: request with no later approval for the same id).
  • Status row: flash messages (4 s TTL), last loop output line (» …), otherwise the key hints with the quit hint first (clipping eats the right end).

11. Visual pass (2026-08-27)

The first render pass was flat: single truncated lines, raw JSON tool results, and a one-keystroke quit. The visual pass changed:

  • Multi-line text. Newlines are hard breaks; each hard line word-wraps at the pane width. Per-event line caps with a hint keep huge logs bounded.
  • Tool results. The header shows exit N / (error); the body shows the tool's text payload (or stdout/stderr), capped and dim. No raw JSON envelope in the view.
  • Two-step quit. First q arms with a flash hint; a second q inside 3 s quits; any other key disarms.
  • Structure. Blank line between events, 12-column content gutter, bash commands shown on their own dim line.

12. Deviations from the proposal (documented)

  • Native async fn instead of async_trait — the #[async_trait] dep is dropped; the trait uses native async fns (edition 2021, stable).
  • watch() is sync and returns a std::sync::mpsc::Receiver<WatchItem>; the tailer is a std thread. The all-async trait sketch of the doc is a deliberate deviation: the UI drains it synchronously, avoiding runtime-context traps.
  • No tui-textarea — the doc allows a textarea or an editor shell-out; the single-line input + Ctrl+E editor keeps the dep count down.
  • CLI: positional SESSION arg + --config (the doc's --session s1 form is equivalent).
  • Two-step quit: first q arms, second q inside 3 s quits, any other key disarms. Ctrl+Q maps to the same key.
  • Approval wire format: approval may carry arguments (edited JSON) — additive field, no v bump (P1b).
  • Cancel target: cancel events carry target: "turn".
  • Read cap: read_events reads the last 50 MB (Phase 1 limit; cursor pagination is a later enhancement). The transcript renders at most the newest 2000 events; the log file is the record.
